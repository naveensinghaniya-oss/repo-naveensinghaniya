# repo-naveensinghaniya

This is a portfolio website for Naveen Singhaniya built with HTML, CSS, and JavaScript.

## Features
- Responsive portfolio layout
- About, Skills, Projects, and Contact sections
- Mobile-friendly navigation
- Clean modern design
- Simple JavaScript interaction

## Files
- `index.html`
- `styles.css`
- `script.js`

## How to view locally
Open `index.html` in your browser.

## GitHub Pages
This site is configured to deploy from the `main` branch and the root folder.
